APLIKASI STOK MINUMAN - ONLINE SUPABASE

Versi ini terhubung ke Supabase sehingga data stok/transaksi dapat dipakai bersama dari beberapa HP.

Login:
- Gunakan akun yang dibuat di Supabase Authentication > Users.
- Admin yang sudah dibuat pada proyek Supabase menjadi Admin.

Fitur:
- Login Admin/Karyawan
- Dashboard omzet hari ini
- Penjualan / nota
- Barang masuk -> Gudang
- Pindah stok Gudang <-> Etalase
- Pengeluaran tanpa penjualan
- Stok
- Riwayat
- Kelola Barang (Admin)
- Database online Supabase

Catatan keamanan:
- Aplikasi hanya memakai Publishable Key. Jangan memasukkan sb_secret... atau service_role ke file HTML.
- Agar bisa dipakai dari HP lain, folder ini harus di-host melalui HTTPS.
- Akun karyawan dapat dibuat dari Supabase Authentication > Users; profil baru otomatis menjadi role karyawan.
